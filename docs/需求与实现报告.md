# 自动键鼠活动工作记录软件：需求与实现报告

## 当前需求

目标是一款后台静默运行的桌面软件，用于自动记录电脑键鼠活动，并统计每天上下班时间和工作时段。

核心要求：

- 开机后自动后台启动。
- 默认最小化到系统托盘，不主动弹窗打扰。
- 监听系统全局鼠标、键盘活动，但只判断“有没有动作”。
- 暂不记录具体按键内容，不记录输入文字，不截图，不读取用户文件。
- 每天 0 点重置当天统计。
- 当天第一次键鼠活动记为“本日开始工作时间”。
- 当天最后一次键鼠活动记为“本日结束工作时间”。
- 长时间无操作时判定为离开，默认阈值为 5 分钟，可在 UI 中设置。
- 数据本地保存，同时预留数据库同步能力。
- 简单 UI 支持查看历史记录、导出报表、设置休眠阈值、开机自启开关、同步开关。
- 后续可能增加可查看的 Web 后台。
- 当前开发环境为 macOS，优先保证 macOS 可运行。
- Windows 平台保留实现入口，后续做兼容验证和打包。
- 最终交付形式应是可安装软件：macOS 提供 `.dmg`，Windows 提供 `.exe` 或 `.msi`。
- 安装后用户可直接打开软件完成首次配置，配置会被本地记住。
- 软件后续启动时自动读取已保存配置，无需重复设置。

## 推荐技术方案

当前项目采用：

- 桌面框架：Tauri 2
- 后台核心：Rust
- 前端界面：React + TypeScript + Vite
- 本地数据库：SQLite
- 数据导出：CSV
- macOS 活动检测：`IOHIDSystem HIDIdleTime`
- Windows 活动检测：`GetLastInputInfo`

选择原因：

- Tauri 体积小，适合长期后台常驻。
- Rust 适合系统级能力、托盘、自启、本地数据库和跨平台平台层封装。
- macOS `IOHIDSystem HIDIdleTime` 和 Windows `GetLastInputInfo` 都属于系统空闲时间读取方案，比全局键盘 Hook 更符合隐私要求。
- SQLite 足够支撑本地记录和后续同步状态管理。

## 软件形态要求

最终软件应具备：

- macOS：生成 `.dmg` 安装包，用户拖入 Applications 后使用。
- Windows：生成 `.exe` 或 `.msi` 安装包，用户双击安装。
- 首次打开时进入设置界面，可配置休眠阈值、开机自启、数据库同步开关。
- 配置保存到本地 SQLite，后续打开自动读取。
- 软件关闭主窗口后仍可在系统托盘/菜单栏后台运行。
- 数据默认先写本地，再按同步配置上传数据库。
- 后续可增加“首次设置向导”，包含隐私说明、同步地址、账号或 Token、开机自启确认。

## 当前数据模型

本地 SQLite 表：`daily_work_records`

字段：

- `date`：日期，主键。
- `first_activity_at`：当天第一次活动时间。
- `last_activity_at`：当天最后一次活动时间。
- `active_minutes`：当天估算活跃分钟数。
- `idle_minutes`：当天空闲分钟数，当前预留。
- `sync_status`：同步状态，例如 `pending` / `synced`。
- `updated_at`：最后更新时间。

设置表：`settings`

- 当前用 `key = app` 保存 JSON 设置。
- 包含休眠阈值、开机自启、数据库同步开关。

## 隐私边界

当前方案的隐私设计：

- 不读取具体按键。
- 不保存键盘输入内容。
- 不保存鼠标坐标。
- 不截图。
- 不读取用户文件。
- 默认只保存活动时间、统计分钟数、同步状态。

macOS 第一版优先使用 `IOHIDSystem HIDIdleTime`，Windows 使用 `GetLastInputInfo`。这两种方式都只告诉程序“系统最后一次输入距离现在多久”，不需要捕获输入内容。

## macOS 权限说明

macOS 对后台输入活动检测有系统隐私限制。首次运行后，如果系统提示权限，需要在：

`系统设置 -> 隐私与安全性 -> 辅助功能 / 输入监控`

允许 Activity Worklog 或当前开发运行的终端/构建产物。当前方案不需要读取文件、截图或保存按键内容。

## 下一步建议

建议开发顺序：

1. 安装 Rust/Cargo 与 npm 依赖，并在 macOS 上运行 Tauri 开发环境。
2. 修正 macOS 编译细节，优先让 macOS 开发版可启动。
3. 完善托盘菜单：显示、暂停记录、退出。
4. 实现真正的开机自启开关状态联动。
5. 增加活动时段表，记录一天内多段工作/离开区间。
6. 增加数据库同步配置页面，例如服务器地址、Token、同步频率。
7. 在 Windows 上验证 `GetLastInputInfo` 和打包流程。
8. 增加 Web 后台，读取同步后的日报、周报、月报。

## 当前打包状态

已准备好 Tauri 打包配置，源码会保留在 `/Applications/code/ere`。

当前尝试在 macOS 安装 Rust/Cargo 工具链用于生成 `.dmg`，但下载过程长时间无响应，已先停止等待。后续只要本机 Rust/Cargo 安装完成，即可执行：

```bash
cd /Applications/code/ere
npm install
npm run tauri:build
```

macOS 安装包通常输出到：

```text
src-tauri/target/release/bundle/dmg/
```

Windows 安装包需要在 Windows 环境或 CI 中执行同样的 `npm run tauri:build`，通常输出 `.exe` 或 `.msi` 到：

```text
src-tauri\target\release\bundle\
```
