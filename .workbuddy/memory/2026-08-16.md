- **验证**：`npm run build`（tsc+vite）通过；`cargo check` 通过。`tauri build`（带密钥）生成规范 updater 产物：`latest.json`（含 signature）、`Activity Worklog.app.tar.gz`、`.app.tar.gz.sig`，位于 `src-tauri/target/release/bundle/macos/`；`Activity Worklog_0.2.0_aarch64.dmg` 由 bundle_dmg.sh 成功生成（本次未失败），`hdiutil verify` VALID，已复制到根目录替换旧 DMG（旧版不含 updater 功能）。
- **注意**：本环境 `tauri build` 不会自动签名 updater 产物（日志无 Signing、latest.json 缺 signature），需手动 `tauri signer sign --private-key-path .tauri/activity-worklog.key -p "" <tarball>` 后用 node 从 .sig 解码提取 64 字节 Ed25519 签名（base64 后 88 字符）注入 `latest.json.platforms.darwin-aarch64.signature`。CI 中 `tauri-action` 依赖 `TAURI_SIGNING_PRIVATE_KEY` 环境变量（secret 内容不要带尾部换行）。
