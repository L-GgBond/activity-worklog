# Activity Worklog

一款隐私友好的桌面端工作时间记录工具。它通过系统“最后一次输入时间”判断鼠标键盘是否有活动，用于自动统计每天首次活动时间、末次活动时间和工作时段。

## 当前定位

- 当前开发环境：macOS。
- 优先保证 macOS 可运行，同时保留 Windows 平台实现。
- 默认后台静默运行，并最小化到系统托盘。
- 只记录“是否有活动”和活动时间，不记录输入内容、不截图、不读取文件。
- 本地 SQLite 保存记录，支持 CSV 导出、月度考勤 CSV（含迟到/早退/加班）与图片/PDF 报表。
- 支持补录没有记录的一天（忘开机、换机、补卡），并自动校验时段重叠。
- 支持把记录推送到自建服务器（`POST /api/sync/records`），也可从服务器补回本地缺失的历史（`GET /api/sync/records`）；时段明细同样可同步（`/api/sync/segments`），本地删除只删本设备的服务端数据（`POST /api/sync/delete`）。
- 多设备各存各的：服务端按 `(device_id, date)` 存储，同一天多台机器不再互相覆盖，报表取当天活跃最多的设备。
- 后台每天自动热备（保留最近 7 份），JSON 全量导出包含设置，换机可一键恢复配置。
- 工作日可按实际排班设置（每周工作日多选 + 法定节假日 + 调休补班），报表达成率、迟到早退与考勤导出都按这张日历计算。
- 数据分析页含日历热图（最近三个月逐日活跃深浅），可随图片/PDF 报表一起导出。
- 关于页支持检查更新并**一键下载安装**（下载 + 校验签名，安装后自动重启）。
- 应用锁：启动、隐藏窗口或托盘锁定后需要密码才能看到记录，可生成一次性恢复码；首次引导即可设置。
- 隐藏入口：macOS 不出现在 Dock / ⌘Tab，Windows 不进任务栏，保留托盘图标作为唯一入口。
- 设置页可直接看到数据库路径并打开数据目录，便于手动备份与迁移。
- 0.4.0 体验升级：设置页支持搜索、锚点跳转与折叠；危险操作统一模态确认；密码框可显隐；Webhook 与通知可发测试；自动备份可点选恢复；窗口位置（含多屏）记忆；暗色/警告色全部令牌化。
- 应用与窗口识别（可选，默认关闭）：开启后自动记录前台应用与窗口标题，分析页按应用统计时长、查看单日窗口明细；**纯本地、不参与同步、可随时关闭或清空**，关闭标题记录后只保留应用名。

## 项目结构

- `src/`：前端界面。
- `src-tauri/`：Tauri + Rust 后台。
- `docs/需求与实现报告.md`：需求、设计、已完成内容和后续路线。

## 常用命令

```bash
npm install
npm run tauri:dev
npm run tauri:build
```

## 生成安装包

macOS：

```bash
cd /Applications/code/ere
npm install
npm run tauri:build
```

生成位置通常是：

```text
src-tauri/target/release/bundle/dmg/
```

Windows：

```powershell
cd C:\你的项目路径\ere
npm install
npm run tauri:build
```

生成位置通常是：

```text
src-tauri\target\release\bundle\
```

源码会保留在项目目录中，安装包只是额外生成的文件。

## macOS 权限说明

macOS 对后台输入活动检测有系统隐私限制。首次运行后，如果系统提示权限，请到：

`系统设置 -> 隐私与安全性 -> 辅助功能 / 输入监控`

允许 Activity Worklog 或开发中的终端/构建产物。当前方案只读取系统空闲时间，不保存按键内容、不截图、不读取文件。
