# Activity Worklog

一款隐私友好的桌面端工作时间记录工具。它通过系统“最后一次输入时间”判断鼠标键盘是否有活动，用于自动统计每天首次活动时间、末次活动时间和工作时段。

## 当前定位

- 当前开发环境：macOS。
- 优先保证 macOS 可运行，同时保留 Windows 平台实现。
- 默认后台静默运行，并最小化到系统托盘。
- 只记录“是否有活动”和活动时间，不记录输入内容、不截图、不读取文件。
- 本地 SQLite 保存记录，支持 CSV 导出、月度考勤 CSV（含迟到/早退/加班）与图片/PDF 报表。
- 支持补录没有记录的一天（忘开机、换机、补卡），并自动校验时段重叠。
- 支持把记录推送到自建服务器（`POST /api/sync/records`），也可从服务器补回本地缺失的历史（`GET /api/sync/records`）。
- 应用锁：启动、隐藏窗口或托盘锁定后需要密码才能看到记录，可生成一次性恢复码。
- 隐藏入口：macOS 不出现在 Dock / ⌘Tab，Windows 不进任务栏，保留托盘图标作为唯一入口。
- 设置页可直接看到数据库路径并打开数据目录，便于手动备份与迁移。

## 项目结构

- `src/`：前端界面。


## 生成安装包

macOS：

```bash
cd /Applications/code/ere
npm install
npm run tauri:build
```

生成位置通常是：

```text
src-tauri/target/release/bundle/dmg/
```

Windows：

```powershell
cd C:\你的项目路径\ere
npm install
npm run tauri:build
```

生成位置通常是：

```text
src-tauri\target\release\bundle\
```

源码会保留在项目目录中，安装包只是额外生成的文件。

## macOS 权限说明

macOS 对后台输入活动检测有系统隐私限制。首次运行后，如果系统提示权限，请到：

`系统设置 -> 隐私与安全性 -> 辅助功能 / 输入监控`

允许 Activity Worklog 或开发中的终端/构建产物。当前方案只读取系统空闲时间，不保存按键内容、不截图、不读取文件。

## 后续重点

已完成：macOS 编译与 DMG 打包、开机自启、托盘暂停/恢复、多段工作/离开时段表、同步配置页与推送接口、数据分析与报表导出、时段编辑、数据保留期、JSON 全量导入导出、跨平台通知、补录缺失日期、月度考勤 CSV、从服务器恢复历史、数据目录直达。

仍需处理（详见 `docs/用户视角优化清单.md`）：

1. 自动更新：目前只检测版本并跳转下载页，尚未一键下载安装。
2. 多设备同步：服务端以日期为全局主键，同一日期多设备会互相覆盖；删除也不会同步到服务器。
3. 时段明细不同步：换机后只有日汇总，历史某天的上下班时间仍需本地数据才能改。
4. 节假日/调休口径：工作日仍固定按周一至周五，法定节假日与调休补班无法配置。
5. Linux 的离开检测恒为 0（只识别 Windows / macOS）。
6. 数据加密（SQLCipher）：应用锁只挡界面，数据库本身仍是明文 SQLite。
7. 运行日志落盘、Windows CI 构建与签名公证。

详细的代码评审见 `docs/评审与优化建议.md`，用户视角的优先级排序见 `docs/用户视角优化清单.md`。
